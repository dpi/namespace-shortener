# dpi/namespace-shortener-phpcs

[![Packagist Version](https://img.shields.io/packagist/v/dpi/namespace-shortener-phpcs)](https://packagist.org/packages/dpi/namespace-shortener-phpcs)
[![Documentation](https://img.shields.io/badge/docs-website-blue)](https://dpi.github.io/namespace-shortener/)

The [PHP_CodeSniffer](https://github.com/PHPCSStandards/PHP_CodeSniffer) standard for Namespace Shortener, which imports the namespaces you choose, and rewrites every usage to go through them.

## Install

```sh
composer require --dev dpi/namespace-shortener-phpcs
```

## Documentation

Read the documentation at [dpi.github.io/namespace-shortener](https://dpi.github.io/namespace-shortener/).
