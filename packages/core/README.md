# dpi/namespace-shortener-core

[![Packagist Version](https://img.shields.io/packagist/v/dpi/namespace-shortener-core)](https://packagist.org/packages/dpi/namespace-shortener-core)
[![Documentation](https://img.shields.io/badge/docs-website-blue)](https://dpi.github.io/namespace-shortener/)

The tool-independent logic behind Namespace Shortener. You'd normally install it through the package for your tool, rather than directly.

## Install

```sh
composer require --dev dpi/namespace-shortener-core
```

## Documentation

Read the documentation at [dpi.github.io/namespace-shortener](https://dpi.github.io/namespace-shortener/).
